# База знаний отдела продаж Академии TOP

Статический многостраничный сайт для размещения на GitHub Pages. Внешние библиотеки и веб-шрифты не требуются; оформление использует системные шрифты.

## Запуск локально

Откройте терминал в папке сайта и выполните:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`. Не открывайте `index.html` напрямую через `file://`, так как сайт загружает JSON-файлы через fetch.

## Публикация на GitHub Pages

1. Распакуйте архив сайта на компьютере. Сам ZIP-архив в репозиторий загружать не нужно.
2. Создайте репозиторий GitHub.
3. Загрузите содержимое этой папки в корень репозитория.
4. Откройте Settings → Pages.
5. В разделе Build and deployment выберите Deploy from a branch.
6. Выберите ветку `main` и папку `/ (root)`, сохраните.

## Содержание

- `index.html` — главная страница.
- `pages/` — отдельные страницы разделов.
- `assets/site.css`, `assets/site.js` — оформление и логика сайта.
- `assets/files/` — загруженные исходные файлы (без редактирования) до 100 МБ.
- `assets/previews/` — просмотровые PDF-копии для файлов, которые нельзя положить в GitHub из-за ограничения 100 МБ на один файл, и предпросмотры офисных документов.
- `data/` — реестр, навигация и поисковый индекс.

## Важно об исходниках

Содержимое исходных документов не редактировалось. Два PDF-файла больше 100 МБ не включены в исходном виде, поскольку GitHub не принимает отдельные файлы такого размера. Для них созданы визуальные веб-копии; оригиналы остаются в загруженных материалах чата. Дублирующиеся исходные файлы сохранены отдельными позициями.

Поиск по содержимому работает по извлечённому текстовому слою PDF/DOCX/PPTX. Для сканированных PDF без текстового слоя поиск возможен по названию и описанию, а содержание доступно через просмотр файла.


## Комплект поставки

Из-за объёма исходных PDF и ограничений на передачу больших архивов сайт поставляется несколькими архивами:

- `top-sales-site-code.zip` — страницы сайта, стили, логика, реестр и данные.
- `top-sales-materials-01.zip` … `top-sales-materials-06.zip` — файлы и предпросмотры.

Сначала распакуйте `top-sales-site-code.zip`, затем распакуйте все шесть архивов материалов в ту же папку, подтверждая объединение папок. В итоге должна получиться одна папка `top-sales-knowledge-base` со структурой `assets/files`, `assets/previews`, `assets/images`, `data`, `pages`.
